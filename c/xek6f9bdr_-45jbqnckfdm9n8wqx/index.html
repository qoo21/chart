利用規約

Chart Viewer（このサイト）と、Discord サーバーの Bot を利用する際の決まりです。

このサイトについて

Chart Viewer は非公式のファンサイトです。株式会社セガ・株式会社Colorful Palette・クリプトン・フューチャー・メディア株式会社とは関係ありません。

名前とアイコン

Bot の /mypage でマイページを公開すると、Discord の名前とアイコン画像を取得し、Chart Viewer で使用されます。公開していない人の名前とアイコンは表示しません。

送った情報の使い道

Bot に送った情報（譜面の情報・画像・説明・リザルト画面の記録など）は、Bot と Chart Viewer の中でだけ使用されます。

利用方法

Chart Viewer のページを SNS などで紹介・共有するのは自由にして構いません。

禁止事項

  • Bot やサイトに保存されている内部データ、リポジトリを、許可なく使うこと
  • Discord サーバーのルールに反する使い方をすること
  • 不具合を故意に悪用すること

責任について

Bot のデータの漏洩など、Chart Viewer で起きた損害について、運営は一切の責任を負いません。

お問い合わせ

不具合や誤りを見つけた時、聞きたいことがある場合は、Discord サーバーで連絡してください。
